6.  ALGORITHMS USED

Budget Allocation Algorithm:

Input: income category_percentages

For each category: allocated_amount = income × percentage / 100

Time Complexity: O(n)

Expense Tracking Algorithm: remaining_budget = allocated_budget −
total_spent

Spending Pattern Analysis: category_total = sum(expenses where category
= X) percentage = category_total / income

Overspending Detection: If spent > allocated_budget alert user

------------------------------------------------------------------------

7.  MATHEMATICAL FORMULAS

Percentage Allocation: Allocated = Income × (Category Percentage / 100)

Example: 50000 × 0.20 = 10000

Savings Rate: Savings Rate = (Savings / Income) × 100

Example: 10000 / 50000 × 100 = 20%

Compound Interest: A = P (1 + r/n)^(nt)

Where: A = final amount P = principal r = interest rate n = compounding
frequency t = years

Future Value for Monthly Investment (SIP): FV = P × ((1+r)^n − 1) / r

Moving Average (trend detection): MA = (x1 + x2 + … + xn) / n
